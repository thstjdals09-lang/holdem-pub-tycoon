# 🍺 홀덤펍 키우기 (Hold'em Pub Tycoon)

작은 홀덤펍 하나로 시작해서, 테이블을 늘리고 직원을 고용하고 운영진을 스카우트해
대박 펍으로 키우는 **모바일 친화적인 3D 브라우저 방치형(incremental/idle) 게임**입니다.

매장 내부가 [Three.js](https://threejs.org)로 렌더링된 카툰(셀셰이딩) 스타일의 고정 아이소메트릭
씬으로 표현되고, 그 **위에 UI가 오버레이**됩니다 — 스크롤 없이 화면 전체가 게임 화면이에요.
빌드 도구 없이 CDN에서 Three.js를 바로 불러오는 구조라 별도 설치가 필요 없습니다.

## 🖥 화면 구성

```
┌──────────────────────────────────────┐
│ 프로필 Lv·칭호     ┌ 💰 BB / 초당수익 ┐│  ← 좌상단 프로필 / 우상단 재화 지갑
│ ✨  ⚙️             └ 💎 다이아＋│🏆 ┘│     (BB·다이아·트로피를 한 장에, 폭 고정)
│              [부스트 · 🏆대회 남은시간] │
│                                   🎁 │
│                                   📅 │  ← 우측 사이드 레일
│        (3D 매장이 화면을 꽉 채움)   📋 │     (선물·출석·미션·부스트)
│                                   ⚡ │
│                                      │
│             [📜 성장 미션 / 🔁 반복] │  ← 퀘스트 배너(탭하면 해당 화면으로 이동)
├──────────────────────────────────────┤
│  🏗업그레이드   👥운영진   🏆대회   💎상점 │  ← 하단 네비게이션 (4묶음)
└──────────────────────────────────────┘
```

네비를 누르면 아래에서 **바텀시트가 고정 높이로 올라오고, 내용은 시트 안에서만 스크롤**됩니다.
묶음 안의 세부 탭은 시트 맨 위 칩으로 고르고, 마지막으로 본 세부 탭을 기억해요.
페이지 자체는 절대 스크롤되지 않아요. BB로 사는 탭(테이블·시설·직원·인테리어) 위에는 **x1 / x10 / x100 / MAX** 일괄 구매 배수 버튼이 붙어 있어요.
숫자가 바뀌어도 UI 폭이 흔들리지 않게 지갑·퀘스트 배지·카드 버튼은 폭이 고정돼 있어요.

## 🏮 매장 구성

실제 홀덤펍처럼 구역을 나눠 배치했습니다.

| 구역 | 배치물 |
|---|---|
| **뒷벽** | 바 카운터 + 바 스툴 5석 + 백바 주류 선반 · 냉장고 · 주크박스 · TV · 칩 케이지(**🏆 대회 접수대** — 탭하면 대회 탭, 우승할 때마다 트로피가 늘어남) |
| **좌측벽** | VIP룸 커튼 · 다트보드 · 액자 · 라운지 부스 소파 + 러그 + 티테이블 · 출입문 |
| **중앙** | 홀덤 테이블 격자, 테이블마다 펜던트 조명 |
| **천장/벽** | 전구 가랜드, 네온사인, 샹들리에 |

> 아이소메트릭 시점에서는 **좌측벽과 뒷벽만 정면이 보이므로**, 벽에 거는 기물은 전부 그 두 면에만 배치했습니다.

### 🃏 테이블은 진짜 홀덤 테이블

원형 탁자가 아니라 **레이스트랙(스타디움) 형태의 실제 홀덤 테이블**입니다.

- 가죽 레일이 펠트를 링처럼 감싸고, 펠트는 레일보다 살짝 낮게 들어가 있어요
- 펠트 위에 **베팅 라인 · 딜러 반원 · HOLD'EM 로고**가 인쇄되어 있고, 커뮤니티 카드 5장과 팟이 놓여 있어요
- **딜러는 딜러석(긴 변 한가운데)에 실제로 앉아 있고**, 앞에는 칩 트레이와 카드 슈가 있어요
- 딜러 복장은 도감 등급(N/U/R/SR/SSR)에 따라 색이 다르고, 영웅·전설 등급은 발치에 빛이 돕니다
- 플레이어 의자는 딜러석을 비운 나머지 둘레에 4~8석이 고르게 놓입니다

### 🍻 손님이 기물을 실제로 사용해요

손님은 출입문으로 걸어 들어와 **비어 있는 자리를 골라 가서 그 기물을 사용하고** 나갑니다.

| 자리 | 손님 행동 |
|---|---|
| 홀덤 테이블 좌석 | 의자에 앉아서 포커 플레이 |
| 바 스툴 | 앉아서 한잔 (잔이 놓이고 🍻 이펙트) |
| 라운지 소파 | 앉아서 수다 (♥ 이펙트) |
| 다트보드 | 서서 다트를 던짐 (다트가 날아가 꽂힘) |
| 주크박스 | 서서 노래 선곡 (♪ 음표가 떠오름) |

자리는 중복 점유되지 않고, 손님이 떠나면 다시 비어요.
**홀덤 테이블 좌석은 방문객 수만큼 찹니다** — 테이블당 시간당 방문객이 많을수록(마케터·운영진 방문객 효과) 좌석의 35%~95%가 채워지고(업그레이드 → 테이블 탭에 표시), 매장을 열면 손님 대부분이 이미 앉아 있어요.
휴대폰 성능을 위해 손님 수에는 상한(코어 4개 이하 기기 72명, 그 외 128명)이 있고, 손님은 그림자를 그리지 않아요.
손님은 **테이블·바 카운터·캐셔 카운터를 뚫고 지나가지 않고 통로로 돌아서 걸어갑니다** (장애물 회피 조향).

### 💎 다이아 말풍선
테이블에 앉은 손님이 가끔(25~55초, 운영진 "다이아 말풍선" 효과만큼 짧아짐) **💎 말풍선**을 띄웁니다. **터치하면 다이아 1~2개**를 받아요.
말풍선은 12초 뒤 사라지고, 앱을 켜둔 동안에만 떠요. (예전의 다이아 금고·시간당 자동 적립은 다이아가 너무 쉽게 모여서 없앴어요)

### 👤 캐릭터 디자인

- 손님: 머리카락(숏·단발·장발·포니테일·삐죽머리·똥머리) / 머리색 / 셔츠 / 바지를 무작위로 조합해 매번 다른 사람이 들어와요
- 딜러: 흰 셔츠 + 등급색 조끼 + 보타이 + 딜러 바이저, 테이블 위로 팔을 뻗고 앉은 자세
- 바텐더: 조끼 + 보타이 유니폼, 마케터는 캡 모자
- 머리카락과 표정(눈·볼터치·입)은 머리 구체의 텍스처 한 장에 그려서, 디테일을 올려도 메시 수가 늘지 않게 했습니다

## 🕹 게임 방법

수동 클릭으로 돈을 버는 방식이 아니라, **테이블이 스스로 초당 수익을 벌어들이는 완전 자동 방치형**입니다.
몇 초마다 동전이 튀어오르며 번 금액이 떠요(설정에서 끌 수 있어요).
**3D 씬의 테이블이나 시설을 직접 탭하면** 그 자리에서 업그레이드 팝업이 뜨고, 빈 자리를 탭하면 새 테이블을 놓습니다.
카메라는 회전하지 않고 **드래그로 매장 안을 둘러보거나 핀치로 확대/축소**만 됩니다.

### 📜 성장 미션 (튜토리얼)

화면 아래 배너에 **21단계짜리 성장 미션**이 한 단계씩 뜹니다. 쿠키런/메이플 키우기처럼
따라가다 보면 테이블·시설·직원·💎말풍선·가챠·도감·운영진 배치·대회·부스트·출석·프레스티지까지
게임의 모든 시스템을 자연스럽게 한 번씩 써보게 돼요(배너를 탭하면 그 미션을 하는 화면으로 바로 이동). 달성하면 배너가 반짝이고 보상을 받으면 다음 단계로 넘어갑니다.
프레스티지를 해도 진행 단계는 유지됩니다.

### 🔁 반복 퀘스트 (무한)

성장 미션 21단계가 끝나면 같은 배너에서 **반복 퀘스트가 끝없이 이어집니다.** 깰 때마다 회차가 오르고 보상(BB·다이아·무료 뽑기권)이 커져서
진행에 필요한 재화가 계속 들어와요. 목표치도 회차에 따라 커지지만 **항목별 상한**이 있어 후반에도 항상 몇 분 안에 깰 수 있습니다.
출석처럼 하루 한 번만 가능한 행동, 매장 확장(최대 규모가 정해져 있음), 선물 받기는 반복 퀘스트에 넣지 않았어요.
테이블이 최대치에 가까우면 목표 개수도 남은 칸 수로 줄어들고, 더 이상 할 수 없는 퀘스트는 자동으로 다른 퀘스트로 바뀝니다.

성장 미션의 "출석 보상 받기" 같은 목표는 누적 카운터로 판정하므로, 미리 출석을 받아뒀다면 그 단계가 나오자마자 바로 달성 상태가 됩니다 — 진행이 막히지 않아요.

### 모든 업그레이드는 무한합니다
테이블 수·리모델링 레벨·매장 확장·시설 레벨·직원 수는 물론, **장식품과 인테리어 테마도 레벨 개념**이라
한 번 사고 끝나는 항목이 없습니다. 비용은 기하급수로 오르고 효과는 계속 누적돼요.

### 재화
- **BB(💰)** — 테이블/시설 수익. 홀덤 테마에 맞춰 화폐 단위를 BB(빅블라인드)로 표기
- **다이아(💎)** — 테이블 손님의 💎 말풍선 터치·퀘스트·출석·선물·대회 입상으로 모아요. 운영진 가챠·부스트·영구 강화에 사용. 프레스티지해도 사라지지 않아요.
- **트로피(🏆)** — 홀덤 대회에서 모으는 재화. 트로피 상점(영업시간 연장·대회 훈련·명예의 전당·뽑기권 교환·운영진 조각)에서 써요. 프레스티지해도 사라지지 않아요.
- **무료 뽑기권(🎫)** — 반복 퀘스트 보상·트로피 교환으로 받는 소모품. 1장이면 1회, 10장이면 10회, 30장이면 30회 뽑기 버튼이 다이아 대신 무료 뽑기로 바뀝니다.

### 네비게이션 (4묶음 · 세부 탭)
- **🏗 업그레이드** — 모든 강화를 한곳에
  - **테이블**: 홀덤 테이블 추가, 전체 리모델링, 매장 확장(최대 24칸), 시간당 방문객·테이블 좌석 채움률
  - **시설**: 바 카운터·냉장고 무한 강화
  - **직원**: 바텐더/서빙/마케터 고용
  - **인테리어**: 테마 4종(클래식/공주풍/유럽풍/네온) + 등급 강화, 장식품 6종 무한 강화
  - **💎영구**: 다이아로 사는 영구 강화(매출/오프라인 효율/가챠 확률, 리뉴얼해도 유지)
- **👥 운영진**
  - **스카우트**: 운영진 가챠(1회 / 10회 / 30회, 10회마다 R 이상 확정), 가챠 레벨(뽑을수록 오르고 경험치 바로 표시), **🔁 연속 뽑기**, 광고 리워드(하루 1회 무료 뽑기 / 수익 2배)
  - **도감**: 맨 위 **편성 스테이지**(대회 전투력 · 편성한 10명 · 시너지)와 **편성 프리셋 5개**(번호를 눌러 팀 교체, ⚡ 자동 편성). 이름 붙은 운영진 50명(N 14 / U 12 / R 8 / SR 9 / SSR 7) + 상점 전용 신화 등급 "구현모". 등급 필터, 수집률, 중복 조각으로 **★10까지 승급**, **⭐ 일괄 승급**, **⚡ 빠른 배치**, 카드에서 바로 배치/해제. 운영진을 누르면 **🏆 트로피로 승급 조각 구매** 가능
- **🏆 대회** — **대회**(참가·진행·결과) / **트로피 상점**
- **💎 상점**(재화 옆 ＋ 버튼으로도 열림) — 다이아 결제, 상점 전용 신화 운영진 구매, 광고 제거
- **✨ 브랜드 리뉴얼**은 네비에서 빠지고 **좌상단 ✨ 배지**로 열어요 — 누적 수익으로 프레스티지, 영구 수익 배율 + 다이아 보상

### 🔁 연속 뽑기
스카우트 탭에서 묶음(1회씩/10회씩/30회씩)과 멈춤 조건(**SSR 나오면 / SR 이상 나오면 / 새 운영진 나오면 / 재화 다 쓸 때까지**)을 고르고 시작하면,
결과창에서 계속 뽑으면서 누적 회차·등급별 개수·NEW 수·쓴 재화를 보여줘요. 뽑기권이 있으면 뽑기권부터 쓰고, **🎫 뽑기권만 쓰기**를 켜면 다이아는 건드리지 않아요.
"⏹ 멈추기"나 결과창을 닫으면 바로 멈춥니다. 한 번 뽑은 결과창에는 **"n회 더"** 버튼도 있어요.

### 🏆 홀덤펍 대회
우리 펍 대표로 대회에 나가서 **트로피**를 모아요. 한 번에 한 대회만 참가하고, 실제 시간이 흘러야 끝나요(앱을 꺼도 진행).
- **대회 전투력** = 배치한 운영진(등급·별 × 배치 시너지) + 매장(테이블·리모델링) × 대회 훈련. 순위는 참가하는 순간 전투력과 운으로 정해지고, 진행 중엔 남은 인원이 줄어드는 모습으로 공개돼요. 탈락하면 그 시점에 끝나요.
- **참가비**는 BB(대회 시간에 비례, 부스트 뺀 수익 기준). 순위 구간(🥇우승 / 🏅톱3 / 🎖️파이널 테이블 / 💵상금권 / 💥탈락)에 따라 트로피·BB 상금·다이아를 받아요.
- 대회 5단계: 동네 홀덤 대회(30명·2분) → 시티 오픈(80명·5분) → 코리아 챔피언십(200명·10분) → 아시아 포커 투어(500명·20분) → 월드 그랜드 파이널(1000명·40분). **이전 대회에서 상금권(상위 15%, 최소 9위)에 들면 다음 대회가 열려요.**
- 추천 전투력의 3배가 넘는 쉬운 대회는 보상이 줄어서(다이아 없음) 계속 위 대회에 도전하게 돼요.

프로필 레벨이 오를 때마다 다이아가 지급됩니다.

### 운영진 편성 & 특성 시너지
테이블에 개별로 배정하는 방식이 아니라, 보유한 운영진 중 **최대 10명을 "편성"**해 매장 전체 수익에 반영하는 방식이에요.
편성은 **프리셋 5개**에 따로 저장돼서(도감 위 1~5 번호) 상황에 맞는 팀으로 바로 바꿀 수 있어요.

운영진마다 **특성이 2개**씩 있고(역할에서 1개 + 고유 1개), 편성한 10명 중 **같은 특성이 3명 / 5명 / 7명** 모이면 단계별 보너스가 매장 전체에 붙습니다.
10명 × 2개 = 20칸을 6종류가 나눠 가지니까, 3단계를 노리려면 한 특성에 일부러 몰아줘야 해요.

| 특성 | 3명 / 5명 / 7명 |
|---|---|
| 🃏 **딜링** | 전체 수익 +10% / +25% / +50% |
| 🗣️ **처세** | 방문객 +15% / +35% / +70% |
| 🍸 **접객** | 바·시설 수익 +20% / +50% / +100% |
| 🎲 **승부사** | 대회 전투력 +12% / +30% / +65% |
| 🎉 **흥** | 💎 말풍선 빈도 +20% / +50% / +100% |
| 🧠 **두뇌** | 오프라인 효율 +6% / +14% / +28% |

활성화된 시너지 단계 1당 운영진 **장착효과도 +5%**씩 커지고, 정확히 10명을 꽉 채우면 추가 보너스가 붙습니다.
편성 스테이지의 시너지 칩에 현재 인원과 다음 단계까지 몇 명 남았는지가 표시되고, **⚡ 자동 편성**은 특성 조합까지 계산해서 가장 센 팀을 짜줘요.
테이블에 앉은 모습은 배치된 운영진(모자라면 보유했지만 미배치인 인원, 그래도 모자라면 이름 없는 기본 운영진)으로 자동으로 채워져서 빈 테이블처럼 보이는 일이 없어요.

### 운영진 효과 & 별 등급
운영진마다 **고유 보유효과**와 **장착효과**가 있어요.
- **장착효과** — 배치됐을 때만 적용. 역할에 따라 종류가 정해짐(영업=매출, 서비스=시설 수익, 이벤트=💎 말풍선 빈도, 인맥=방문객) + 배치 시너지 배율
- **보유효과** — 도감에 보유만 해도 항상 적용. 운영진마다 매출/시설 수익/다이아/방문객/오프라인 효율/선물 보상 중 하나(장착효과보다 작음)
- 두 효과 모두 등급과 별이 오를수록 커집니다

별은 최대 **★10**이고, 5칸짜리 별 표시가 **빈 별 → 은별(★1~5) → 금별(★6~10)** 순서로 채워집니다.
등급이 낮을수록 중복이 잘 나오는 대신 승급에 필요한 조각 수가 많아요.

### 방문객과 마케터
매장의 "시간당 방문객 수"가 실제로 매출에 반영됩니다(방문객이 많을수록 매출도 커지되, 로그형으로 완만하게 체감). 마케터는 더 이상 매출에 고정 %를 더하는 대신, 이 방문객 수 자체를 늘려주는 역할로 재설계됐어요.

## 👤 계정

Firebase Authentication 기반 아이디/비밀번호 로그인. 처음 접속하면 로그인/계정 만들기 화면부터 뜨고,
로그인한 계정으로 진행 상황이 클라우드(Firestore)에 자동 저장돼 **여러 기기에서 같은 아이디로 이어할 수 있어요.**
설정(⚙️) 탭의 "계정" 섹션에서 비밀번호 변경 / 로그아웃 / 계정 삭제가 가능합니다.

밸런스가 크게 바뀌는 패치에서는 `js/data.js`의 `dataResetVersion` 숫자를 올려 **모든 계정의 게임 데이터를 한 번에 초기화**합니다
(로그인 계정은 유지, 다음 접속 시 새 게임으로 시작).

정식 출시 전에는 테스트 지급 경로(`js/shop.js`, `js/ads.js`)를 반드시 막아야 합니다.

## 🧩 프로젝트 구조

```
holdem-pub-tycoon/
├── index.html          # 풀스크린 셸 (3D 레이어 + HUD 오버레이 + 바텀시트 + 모달 + 로그인 게이트)
├── css/style.css        # 오버레이 UI 스타일 (두툼한 입체 버튼, 프로스티드 글래스)
├── js/data.js            # 밸런스/콘텐츠/상점 데이터 전부
├── js/portraits.js        # 운영진 치비 초상화를 SVG로 생성 (외부 이미지 없음)
├── js/firebase-init.js     # Firebase 앱/Auth/Firestore 초기화 (ES 모듈)
├── js/account.js            # 회원가입/로그인/로그아웃/계정설정 (ES 모듈)
├── js/auth-gate.js           # 로그인 전 풀스크린 게이트 UI (ES 모듈)
├── js/backend.js              # 저장 데이터 어댑터 (로그인 시 Firestore, 아니면 localStorage)
├── js/shop.js                  # 다이아 결제(PortOne V2) (ES 모듈)
├── js/scene3d.js                 # Three.js 3D 매장 씬 (ES 모듈)
└── js/game.js                     # 게임 루프·경제 로직·UI 렌더링 (상점/계정 탭 렌더링 포함)
```

`js/scene3d.js`는 ES 모듈이라 `window.PubScene3D = { init, update, chipBurst }`로 전역에 노출되고,
`game.js`(클래식 스크립트)는 상태가 바뀔 때마다 `PubScene3D.update(snapshot)`을 호출해 3D 씬을 다시 그립니다.
`game.js`는 `PubScene3D.onTap`에 콜백을 등록해 레이캐스팅 탭 결과를 받습니다.

### 3D 씬 설계 메모
- **Fog를 쓰지 않습니다.** 직교(Orthographic) 아이소메트릭 카메라는 씬 전체가 비슷한 깊이에 놓여서
  Fog를 걸면 매장 안쪽 절반이 통째로 하얗게 날아갑니다. 공간감은 하늘 그라디언트 + 그림자로 냅니다.
- 세로로 긴 모바일 화면에서도 테이블이 크게 보이도록 **프러스텀을 가로 기준으로 맞추고**, 대신 팬(드래그)을 허용합니다.
- **매장 슬롯이 늘어나면 바닥과 벽이 실제로 함께 넓어집니다.**
- 테이블 레일은 **안쪽을 뚫은 링으로 압출**해야 합니다. 구멍 없이 압출하면 속이 꽉 찬 덩어리가 되어
  펠트 상판을 통째로 덮어버립니다.
- 펠트의 베팅 라인/로고는 `ExtrudeGeometry`의 UV를 건드리는 대신 **펠트 바로 위에 얹는 투명 평면**으로
  그립니다. 그래야 테이블마다 펠트 색이 달라도 마킹이 그대로 보입니다.
- 이 시점에서는 **좌측벽과 뒷벽만 정면이 보입니다.** 우측벽·앞쪽에 기물을 걸면 뒷면만 보이므로
  벽걸이 기물은 전부 좌측벽/뒷벽에 배치합니다. 출입문도 앞쪽에 세우면 매장을 가려서 좌측벽에 붙였습니다.

### 백엔드 연결 방식

`js/backend.js`의 `GameBackend` 모듈이 저장/불러오기 API 역할을 합니다.
로그인된 계정이 있으면 Firestore(`holdemPub_saves/{uid}`)를 우선 사용하고, `localStorage`는
오프라인 캐시 + 내보내기/가져오기 코드 생성용으로 계속 씁니다. 함수 시그니처(`saveState`, `loadState`,
`resetState`)는 그대로라 다른 백엔드로 바꿀 때도 `game.js`는 건드릴 필요가 없는 어댑터 패턴입니다.
설정 탭에서 저장 데이터를 base64 코드로 내보내기/가져오기 할 수도 있어요.
