# 🍺 홀덤펍 키우기 (Hold'em Pub Tycoon)

작은 홀덤펍 하나로 시작해서, 테이블을 늘리고 직원을 고용하고 인테리어를 꾸며
대박 펍으로 키우는 **모바일 친화적인 3D 브라우저 방치형(incremental/idle) 게임**입니다.
매장 내부가 [Three.js](https://threejs.org)로 렌더링된 카툰(셀셰이딩) 스타일의 고정 아이소메트릭
씬으로 표현되어, 카이로소프트류 타이쿤 게임과 비슷한 느낌을 냅니다. 손님이 직접 매장 입구로 걸어
들어와 빈 테이블에 앉았다가 한동안 머문 뒤 나가는 모습도 볼 수 있어요. 빌드 도구 없이 CDN에서
Three.js를 바로 불러오는 구조라 별도 설치 없이 실행됩니다.

## 🕹 게임 방법

펍은 실제 매장처럼 고정된 아이소메트릭 3D 공간(바닥, 벽, 테이블, 시설, 손님)으로 시각화됩니다.
카메라는 회전하지 않고 핀치(또는 마우스 휠)로 확대·축소만 가능해요 — 타이쿤 게임 특유의 "정면 디오라마" 구도를 위해서예요.

수동 클릭으로 돈을 버는 방식이 아니라, **테이블이 스스로 초당 수익을 벌어들이는 완전 자동 방치형**입니다.
테이블 하나마다 4~8명이 둘러앉은 모습이 보이고, 그 위에 테이블별 초당 수익이 말풍선처럼 떠요
(설정 탭에서 끌 수 있어요). **3D 씬의 테이블이나 시설을 직접 탭하면** 그 자리에서 바로 업그레이드
팝업이 떠서 강화할 수 있고, 빈 자리를 탭하면 새 테이블을 추가할 수 있어요.

- 매장에 테이블이 있으면 **손님이 자동으로 입구에서 걸어 들어와** 빈 좌석에 앉고, 잠시 머물다 나갑니다.
- **재화는 두 가지**: 칩(💰, 테이블 수익으로 획득)과 다이아(💎, 시간이 지나면 조금씩 쌓이고 다이아 금고 업그레이드·프레스티지로 더 늘어남). 다이아는 프레스티지를 해도 사라지지 않아요.
- **매장** 탭: 매장을 확장해 테이블 슬롯을 늘리고, 바 카운터·냉장고·다이아 금고 같은 시설을 설치/업그레이드해요.
- **테이블** 탭: 매장 슬롯이 남아있는 만큼 홀덤 테이블을 추가하고, 전체 테이블을 리모델링해서 수익을 강화해요.
- **직원** 탭: 바텐더/서빙 직원/마케터를 칩으로 고용하고, **딜러는 다이아로 가챠를 뽑아서** 얻어요. 딜러는 일반/희귀/영웅/전설 등급이 있고 등급이 높을수록 테이블 수익 보너스가 커요. 보유한 딜러 수만큼 테이블에 딜러가 배치된 모습도 보여요.
- **인테리어** 탭: 화분, 네온사인, 샹들리에 등 아기자기한 장식을 사서 펍을 꾸미고 추가 수익 보너스를 받아요.
- **프레스티지** 탭: 누적 수익이 충분히 쌓이면 "브랜드 리뉴얼"로 초기화하고 영구 수익 배율 + 다이아 보상을 받을 수 있어요. 다이아와 딜러 컬렉션은 리뉴얼해도 유지돼요.
- 게임을 꺼도 **오프라인 수익**(칩+다이아)이 쌓이고, 다시 접속하면 안내 팝업으로 알려줘요.

## 🧩 프로젝트 구조

```
holdem-pub-tycoon/
├── index.html          # 게임 화면 마크업 (importmap으로 Three.js CDN 로드)
├── css/style.css        # 아기자기한 파스텔 톤 UI 스타일
├── js/data.js            # 밸런스 수치(테이블/직원/장식/프레스티지 설정)
├── js/backend.js         # 저장 데이터 어댑터 (localStorage 기반, 실제 API로 교체 가능)
├── js/scene3d.js          # Three.js 3D 매장 씬 렌더링 (ES 모듈)
├── js/game.js              # 게임 루프·경제 로직·2D UI 렌더링
└── assets/img/cards/     # Kenney.nl CC0 카드 이미지
```

`js/scene3d.js`는 ES 모듈이라 `window.PubScene3D = { init, update, chipBurst }`로 전역에 노출되고,
`game.js`(클래식 스크립트)는 구매/고용 등 상태가 바뀔 때마다 `PubScene3D.update(snapshot)`을 호출해
3D 씬을 다시 그립니다. `game.js`는 `PubScene3D.onTap`에 콜백을 등록해서, 3D 씬에서 테이블/시설을
탭했을 때 레이캐스팅으로 어떤 오브젝트가 탭됐는지 전달받아 업그레이드 팝업을 띄웁니다.
Three.js는 CDN(jsDelivr)에서 ES 모듈로 불러오므로 npm 설치가 필요 없어요.

### 백엔드 연결 방식

`js/backend.js`의 `GameBackend` 모듈이 저장/불러오기 API 역할을 합니다.
지금은 브라우저 `localStorage`를 사용하지만, 함수 시그니처(`saveState`, `loadState`, `resetState`)를
그대로 두고 내부 구현만 실제 서버 `fetch()` 호출로 바꾸면 진짜 백엔드(Node/Express, Firebase 등)로
쉽게 교체할 수 있도록 어댑터 패턴으로 분리해두었습니다. `game.js`는 `GameBackend`가 로컬 저장소인지
원격 서버인지 알 필요가 없습니다.

설정 탭에서 저장 데이터를 base64 코드로 내보내기/가져오기 할 수도 있어요.

## 🚀 로컬 실행

빌드 과정은 없지만, 3D 씬이 ES 모듈(`<script type="module">` + importmap)로 Three.js를 불러오기 때문에
**반드시 로컬 정적 서버로 열어야 합니다.** (`index.html`을 `file://`로 직접 열면 브라우저 보안 정책 때문에
모듈이 로드되지 않아 3D 화면이 비어 보일 수 있어요 — 나머지 2D UI는 정상 동작합니다.)

```bash
# 예시 (Python이 있다면)
python -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```
