등급 카드 프레임

GameAssets.rarityFrame("legendary", { w: 124, name: "강민혁", portrait: dataUri }) — portrait에 portraits.js가 만든 data URI를 넘기면 초상화가 안에 들어간다. 등급이 높을수록 뒤에서 뻗는 광선이 많아진다.

등급 배지

GameAssets.rarityBadge("epic", { w: 46 }) — 목록 카드 구석에 붙이는 작은 알약.

대회 트로피 5단계

data.js의 tournament.tiers와 id가 1:1로 맞는다. 왼쪽이 AI로 그린 PNG(assets/img/trophy/), 오른쪽이 코드로 그린 SVG 대체본 (GameAssets.trophy("world")) — PNG를 못 받아도 화면이 비지 않는다.

프레스티지 건물 4단계

리뉴얼 단계를 보여주는 외관. 마찬가지로 PNG + SVG 대체본 한 쌍씩. GameAssets.building(3, { size: 120 })
